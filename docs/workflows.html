Workflow Examples

End-to-end recipes — from a NetworkX graph to an interactive VR visualization in as few steps as possible.

Each workflow below is self-contained and runnable from a Jupyter notebook inside the DataDiVR_WebApp/ directory (with the Flask server running). Copy the code into a notebook cell and adapt the graph to your data.

Quickstart Multiple layouts Cluster groups & legend JSON file → project Interactive analysis Language UI commands

1 — Quickstart: graph → VR in one call

Upload

The minimal path: one NetworkX graph, one layout, one call. Useful when you just want to get your data into the viewer as fast as possible.

  1. Import helpers and create a NetworkX graph

    import networkx as nx
import nx2json as nx2j

# Any nx.Graph works — replace this with your own data
G = nx.karate_club_graph()
print("Nodes:", G.number_of_nodes(), " Links:", G.number_of_edges())

  2. Set project name and description

    G.graph['projectname'] = 'KarateClub'
G.graph['info']        = 'Zachary karate club — classic social network benchmark.'
G.graph['layoutname']  = 'spring-3d'

  3. Compute a 3-D layout and assign node positions

    pos = nx.spring_layout(G, dim=3, k=0.3, iterations=50, seed=42)
nx.set_node_attributes(G, {n: tuple(v) for n, v in pos.items()}, name='pos')

  4. Set node and link colors (RGBA tuples, 0–255)

    nx.set_node_attributes(G, {n: (0, 120, 255, 200) for n in G.nodes()}, name='nodecolor')
nx.set_edge_attributes(G, (0, 120, 255, 150), name='linkcolor')

  5. Create the project — one call generates all files

    nx2j.create_project([G])
    Project folder static/projects/KarateClub/ is created with all BMP/PNG textures and JSON metadata. Reload the project dropdown in the DataDiVR browser UI to see it.
Note: nx2j.create_project() is a convenience wrapper around nx2j.make_json() + uploaderGraph.upload_filesJSON(). Use the lower-level functions if you need to inspect or save the intermediate JSON.

2 — Multiple layouts of the same graph

Upload

Each layout is a separate nx.Graph object with the same nodes but potentially different edge subsets, positions, and colors. The VR viewer lets users step through them with the forward/back arrows. Taken from _GenerateProject_Example.ipynb.

  1. Build the base graph and set shared project metadata

    G = nx.circular_ladder_graph(400)
G.graph['projectname'] = 'MultiLayout-Demo'
G.graph['info']        = 'Same graph, five layouts with different edge subsets and color schemes.'

# Optional: give every node a name and annotation
for n in G.nodes():
    G.nodes[n]['name']       = 'Node_' + str(n)
    G.nodes[n]['annotation'] = {'group': 'A' if n % 2 == 0 else 'B'}

  2. Create one Graph object per layout

    import random
import numpy as np

def random_edge_subset(G, keep_fraction, seed):
    """Return a copy of G keeping only a random fraction of edges."""
    rng = random.Random(seed)
    G_sub = G.copy()
    to_drop = rng.sample(list(G_sub.edges()), int(G_sub.number_of_edges() * (1 - keep_fraction)))
    G_sub.remove_edges_from(to_drop)
    return G_sub

# Layout 1 — 75 % of edges, blue, RGBA tuples
G_lay1 = random_edge_subset(G, keep_fraction=0.75, seed=42)
G_lay1.graph['layoutname'] = 'layout1-blue'
pos1 = {n: tuple(v) for n, v in nx.spring_layout(G_lay1, dim=3, seed=1).items()}
nx.set_node_attributes(G_lay1, pos1, name='pos')
nx.set_node_attributes(G_lay1, {n: (0, 0, 255, 200) for n in G_lay1.nodes()}, name='nodecolor')
nx.set_edge_attributes(G_lay1, (0, 0, 255, 200), name='linkcolor')
nx.set_edge_attributes(G_lay1, 'Blue connections', name='linkcolorname')

# Layout 2 — 60 % of edges, red, hex strings
G_lay2 = random_edge_subset(G, keep_fraction=0.60, seed=7)
G_lay2.graph['layoutname'] = 'layout2-red'
pos2 = {n: v.tolist() for n, v in nx.spring_layout(G_lay2, dim=3, seed=2).items()}
nx.set_node_attributes(G_lay2, pos2, name='pos')
nx.set_node_attributes(G_lay2, {n: '#ff0000' for n in G_lay2.nodes()}, name='nodecolor')
nx.set_edge_attributes(G_lay2, '#ff0000', name='linkcolor')
nx.set_edge_attributes(G_lay2, 'Red connections', name='linkcolorname')

# Layout 3 — 50 % of edges, green, 8-digit hex with alpha
G_lay3 = random_edge_subset(G, keep_fraction=0.50, seed=99)
G_lay3.graph['layoutname'] = 'layout3-green'
pos3 = {n: np.asarray(v) for n, v in nx.spring_layout(G_lay3, dim=3, seed=3).items()}
nx.set_node_attributes(G_lay3, pos3, name='pos')          # numpy arrays are supported
nx.set_node_attributes(G_lay3, {n: '#00cc0080' for n in G_lay3.nodes()}, name='nodecolor')
nx.set_edge_attributes(G_lay3, '#00cc0080', name='linkcolor')
nx.set_edge_attributes(G_lay3, 'Green connections', name='linkcolorname')
    Color formats: all three are equivalent to DataDiVR — RGBA tuples, #rrggbb hex, and #rrggbbaa hex-with-alpha are all accepted in the same project.

  3. Create the project from all layouts at once

    Graphs = [G_lay1, G_lay2, G_lay3]
nx2j.create_project(Graphs)
    All three layouts appear in the Layouts dropdown in the DataDiVR viewer. Press the left/right arrows in the VR view to step through them.

3 — Cluster groups with legend

Upload

Assign each node to a named cluster via the "cluster" attribute. DataDiVR builds the selections panel and legend automatically. Links can also be grouped by name via "linkcolorname".

  1. Divide nodes into groups and set the cluster attribute

    G_clusters = G.copy()
G_clusters.graph['layoutname'] = 'layout-clusters'
G_clusters.graph['projectname'] = 'ClusterDemo'

num_nodes = G_clusters.number_of_nodes()
for n in G_clusters.nodes():
    if   n < num_nodes // 3:        G_clusters.nodes[n]['cluster'] = 'Group Alpha'
    elif n < 2 * num_nodes // 3:   G_clusters.nodes[n]['cluster'] = 'Group Beta'
    else:                            G_clusters.nodes[n]['cluster'] = 'Group Gamma'

  2. Assign node colors matching their cluster

    NODE_COLORS = {
    'Group Alpha': (255, 200,   0, 220),   # yellow
    'Group Beta':  (255, 120,   0, 220),   # orange
    'Group Gamma': (  0,  80, 220, 220),   # blue
}
nx.set_node_attributes(G_clusters,
    {n: NODE_COLORS[G_clusters.nodes[n]['cluster']] for n in G_clusters.nodes()},
    name='nodecolor')

  3. Assign link colors and names per edge

    # Identify which group each node belongs to
groups = {g: {n for n in G_clusters.nodes() if G_clusters.nodes[n]['cluster'] == g}
          for g in NODE_COLORS}

d_linkcolors = {}
d_linknames  = {}
for u, v in G_clusters.edges():
    for group_name, group_set in groups.items():
        if u in group_set and v in group_set:
            d_linkcolors[(u, v)] = NODE_COLORS[group_name]
            d_linknames [(u, v)] = group_name + ' links'
            break
    else:
        d_linkcolors[(u, v)] = (160, 160, 160, 120)
        d_linknames [(u, v)] = 'Cross-group links'

nx.set_edge_attributes(G_clusters, d_linkcolors, name='linkcolor')
nx.set_edge_attributes(G_clusters, d_linknames,  name='linkcolorname')

  4. Set positions and create the project

    pos = {n: tuple(v) for n, v in nx.spring_layout(G_clusters, dim=3, seed=13).items()}
nx.set_node_attributes(G_clusters, pos, name='pos')

nx2j.create_project([G_clusters])
    The Selections panel in DataDiVR lists Group Alpha, Group Beta, Group Gamma. The legend panel shows the matching colors. Clicking a group name in the panel highlights all nodes in that cluster.

4 — Save to JSON, reload, and create project

Upload

Use this pattern when you want to share a graph file, regenerate a project without re-running the full pipeline, or load a graph file produced by an external tool.

  1. Serialize a list of graphs to the DataDiVR JSON format

    import json, os
import nx2json as nx2j

Graphs = [G_lay1, G_lay2, G_lay3]   # your list of nx.Graph layouts

merged = nx2j.make_json(Graphs, save_json=True)
# Saves <projectname>.json in the current working directory
# Returns the dict so you can inspect it

    Alternatively, save to a specific path:

    merged = nx2j.make_json(Graphs)
with open('temp-files/MyGraph.json', 'w') as f:
    json.dump(merged, f, indent=4)

  2. Later: load the JSON file and create the project

    import json
import uploaderGraph as uG

with open('temp-files/MyGraph.json', 'r') as f:
    G_merged = json.load(f)

uG.upload_filesJSON(G_merged, overwrite=True)
    The project is recreated from the JSON file. Set overwrite=True to replace an existing project silently; set overwrite=False to be prompted before overwriting.
Working with existing JSON files: if you receive a .json file in the DataDiVR graph format from a collaborator, skip make_json entirely — just load it with json.load() and pass the dict directly to upload_filesJSON().

5 — Interactive analysis from Jupyter

Analysis

Connect a Jupyter notebook to the running DataDiVR server and push live visual updates — highlight a node, extract a subnetwork, or generate a custom texture — without restarting the server or re-uploading the project.

  1. Start the DataDiVR server and open your project in the browser first

    # In a terminal (not in this notebook):
# python app.py
# Then open http://127.0.0.1:5000 and load your project

  2. Connect the Jupyter client and load the graph

    from dataXplorer import (JupyterClient, SessionManager,
                             TextureGenerator, ProjectFileManager,
                             VisualizerSyncer, AnalysisToolkit)

# Connect to the running server
client = JupyterClient(uid='myNotebook', server_url='http://127.0.0.1:5000')
client.connect()

# Select the project you want to work with
PROJECT_NAME = 'KarateClub'
PROJECT_IDX  = 0  # index in the project dropdown
session = SessionManager(sel_id=PROJECT_IDX, sel_name=PROJECT_NAME, client=client)
G = session.load_graph_from_project()   # loads nodes.json + links.json into nx.Graph
print(f"Loaded: {G.number_of_nodes()} nodes, {G.number_of_edges()} edges")

  3. Build the analysis toolkit

    tex_gen  = TextureGenerator(session)
file_mgr = ProjectFileManager(session)
syncer   = VisualizerSyncer(session)
toolkit  = AnalysisToolkit(session, tex_gen, syncer, file_mgr)

  4. Highlight a node and its direct connections in the VR view

    # Highlight node 5 — yellow overlay pushed live to the VR client
toolkit.highlight_node_withlinks(node_id=5)
    Node 5 and all its connected edges turn yellow in the VR view. The node info panel opens in 3D space showing the node's name and ID.

  5. Extract and highlight a 1-hop subnetwork

    # All direct neighbors of node 5, with a custom purple color
toolkit.extract_and_highlight_subnetwork(
    node_id=5,
    color=(180, 0, 255, 230),
    relayout=False    # keep existing positions
)
    The ego-network of node 5 is highlighted in purple. The subgraph is drawn inline in the notebook for a quick 2-D preview.

  6. Re-layout the subnetwork at the center of the scene

    # Set relayout=True to compute a new 3-D position texture:
# the subnetwork moves to the center; other nodes are pushed to a sphere shell
toolkit.extract_and_highlight_subnetwork(
    node_id=5,
    relayout=True,
    scene_name='ego-node5'  # saved as a persistent layout in pfile.json
)

  7. Highlight a custom list of nodes by name

    # Pass node names as they appear in nodes.json ("n" field)
my_nodes = ['Node_0', 'Node_7', 'Node_15', 'Node_23']
toolkit.extract_and_highlight_subnetwork_from_nodelist(
    nodelist=my_nodes,
    color=(255, 80, 0, 230)  # orange
)

  8. Generate a fully custom color texture from your own analysis

    import networkx as nx

# Example: color nodes by degree centrality
centrality = nx.degree_centrality(G)
max_c = max(centrality.values())

node_color_map = {}
for node_id, c in centrality.items():
    norm = c / max_c                          # 0–1
    r = int(255 * norm)
    b = int(255 * (1 - norm))
    node_color_map[node_id] = (r, 50, b, 220)

# Write texture and register it in pfile.json
tex_gen.generate_node_color_texture(node_color_map, 'degree-centrality', save=True)

# Push it live to the VR client
client.emit('ex', {
    'usr': client.uid,
    'fn': 'updateTempTex',
    'id': None,
    'textures': [{'channel': 'nodeRGB', 'path': f'static/projects/{PROJECT_NAME}/layoutsRGB/degree-centrality.png'}]
}, namespace=client.namespace)
    Nodes are colored on a red-to-blue scale by degree centrality, updated live in the VR view without reloading the project.

6 — Natural-language commands via languageUI

Language UI

The languageUI extension lets you control the DataDiVR viewer by typing plain-text commands in a browser chat panel. The LLM maps your request to a backend function or answers it as a general question.

  1. Start the server and open the Language UI

    # 1. Make sure your API key is in:
#    extensions/languageUI/LUI_funcs/token_doNOTcommit.txt
#    (or set OPENAI_API_KEY in your environment)

# 2. Start the server
#    python app.py

# 3. Open in browser:
#    http://127.0.0.1:5000/LUI/languageUI

  2. Example commands you can type

    What you typeWhat happens
    "search for EGFR"Triggers the node search — the VR viewer highlights the node named EGFR
    "switch to the KarateClub project"Changes the active project in the dropdown
    "run the degree centrality analysis"Triggers the matching analytics event
    "what nodes are in this project?"LLM answers as a general query using the project description
    "how many nodes does this graph have?"LLM answers using project metadata from pfile.json

  3. How the routing works under the hood

    # Simplified version of what POST /LUI/languageUI_process does:
from extensions.languageUI.src import language_interface as lang

# Route the command
result = lang.route_command("search for EGFR")
# → {"type": "action", "function": "search_by_name", "args": {"val": "EGFR"}}

# Build the socket message and dispatch it
msg = lang.create_message(result['function'], result['args'],
                              lang.ACTION_REGISTRY[result['function']]['file_path'])
# → {"fn": "node", "id": "search", "val": "EGFR", "usr": "…", "feedback": "…"}

  4. Register a new action so the LLM can call it

    # Add to event_handler/execute_events/my_events.py

def highlight_top_hubs(message, room, project):
    """
    Highlight the top N most-connected hub nodes in the current graph.
    Args:
        top_n (int): How many hubs to highlight. Default is 10.
    """
    top_n = message.get('args', {}).get('top_n', 10)
    # … compute degree, generate texture, emit updateTempTex …

    Then add the mapping in language_interface.py:

    FUNCTION_FN_MAPPING["my_events"] = "analytics"
    After restarting the server, typing "highlight the top 5 hubs" in the Language UI chat will call your new function.

  5. Clear conversation memory to start fresh

    from extensions.languageUI.src.language_interface import clear_memory
clear_memory()   # resets the LangChain ConversationBufferMemory
