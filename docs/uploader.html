uploader

CSV-based data ingestion — converts raw coordinate and color CSV files into GPU-ready textures.

uploader.py

This module handles the CSV upload path. Users supply comma-separated files for node positions, node colors, link topology, and link colors. The module converts them into BMP / PNG texture images and a JSON project index that the VR renderer reads at runtime.

For the JSON-based upload path (recommended for new projects), see uploaderGraph.

Upload entry point

upload_filesNew

(request) → str function

Main upload handler for CSV-format projects. Reads multipart form files from a Flask request, creates the project folder if needed, generates all textures (positions, colors, links), writes nodes.json and pfile.json, and returns an HTML status string.

Expected form file keys:

KeyContent
nodesXYZCSV: one row per node — x,y,z
nodesRGBCSV: one row per node — r,g,b,a
linksCSV: one row per link — source_id,target_id
linksRGBCSV: one row per link — r,g,b,a
npropCSV: node property / annotation rows
labelsCSV: cluster label rows
legendFilesImage files saved into legends/
new_nameForm field: the project namespace / folder name
Returns: HTML string with per-step SUCCESS / ERROR messages

Project management

makeProjectFolders

(name) → None function

Creates the full directory tree for a new project and writes an empty pfile.json skeleton.

ParameterTypeDescription
namestrProject name (used as folder name under static/projects/)

Creates these sub-folders:

static/projects/<name>/
  layouts/      # high-byte position textures
  layoutsl/     # low-byte position textures
  layoutsRGB/   # node color textures
  links/        # link topology textures
  linksRGB/     # link color textures
  legends/      # legend image files
  pfile.json    # project index

check_ProjectFolder

() → None function

Ensures static/projects/ exists. If GD.json is missing, copies the demo project into place.

loadProjectInfo

(name) → Response function

Returns a Flask JSON response listing all file names in each asset subfolder of the named project.

ParameterTypeDescription
namestrProject name
Returns: jsonify(layouts, layoutsRGB, links, linksRGB) or the string "no such project"

loadAnnotations

(name) → dict function

Loads and returns the names.json annotation file for the named project.

Texture generators

makeXYZTexture

(project, pixeldata, name, latlon_flag) → str function

Encodes 3-D node positions into a pair of 8-bit RGB BMP images (high and low bytes) using a 16-bit encoding scheme that gives the VR renderer sub-pixel precision.

ParameterTypeDescription
projectstrProject name
pixeldatadict{"name": str, "data": [[x,y,z], …]}
namestr | NoneOverride texture file name (optional)
latlon_flagboolIf True, interprets data as [lat, lon] and converts via geodetic_to_geocentric

Output files: layouts/<name>.bmp (high), layoutsl/<name>l.bmp (low)

Returns: HTML success/error string

makeNodeRGBTexture

(project, pixeldata, name) → str function

Creates a 128×H RGBA PNG texture encoding per-node colors. Accepts both RGBA tuples and hex strings.

ParameterTypeDescription
pixeldatadict{"name": str, "data": [(r,g,b,a), …]}

Output file: layoutsRGB/<name>.png

Returns: HTML success/error string

makeLinkTexNew

(project, links, name) → str function

Encodes link topology into a 1024×H RGB BMP (two pixels per link — source and target node IDs) and writes links.json alongside it.

ParameterTypeDescription
linksdict{"name": str, "data": [[src_id, tgt_id], …]}

Output files: links/<name>.bmp, links.json

makeLinkTexNew_withoutJSON

(project, links, name) → str function

Same as makeLinkTexNew but does not write links.json. Used when the JSON is handled separately (e.g., when combining multiple link lists).

makeLinkTexNew_withoutJSON_2

(project, links_ids_project, links, name) → str function

Like makeLinkTexNew_withoutJSON but uses a global link-ID lookup (links_ids_project) so that per-layout link bitmaps share a consistent edge index across all layouts.

ParameterTypeDescription
links_ids_projectdictMaps global link index → [src, tgt]
linksdictPer-layout link dict with "data" key

makeLinkRGBTex

(project, linksRGB, name) → str function

Creates a 512×H RGBA PNG texture encoding per-link colors. Pixels map 1:1 to the link index.

ParameterTypeDescription
linksRGBdict{"name": str, "data": [(r,g,b,a), …]}

Output file: linksRGB/<name>.png

makeLinkRGBTex_2

(project, links_ids_project, linksRGB, name) → str function

Like makeLinkRGBTex but uses the global link ID dict for consistent pixel placement across multiple layouts.

makeLinksjson

(project, links) → None function

Writes links.json — the flat link list used by the analytics engine. Each entry has {"id", "s", "e"}.

makeLinksjson_multipleLinklists

(project, links) → None function

Writes linkslayouts.json containing per-layout link lists, used when different layouts show different subsets of edges.

Coordinate & color utilities

geodetic_to_geocentric

(latitude, longitude) → tuple[float, float, float] function

Converts geographic coordinates (latitude / longitude in degrees) to geocentric Cartesian (x, y, z) using the WGS-84 ellipsoid.

ParameterTypeDescription
latitudefloatLatitude in degrees
longitudefloatLongitude in degrees
Returns: (x, -y, z) in metres

normalize_xyz

(coords) → tuple[array, array, array] function

Min-max normalises a list of (x, y, z) tuples independently on each axis to the range [0, 1] using scikit-learn's minmax_scale.

Returns: Tuple of three numpy arrays (x_norm, y_norm, z_norm)

hex_to_rgb

(hx) → tuple[int, int, int] function

Converts a hex color string (with or without leading #) to an RGB integer triple.

hex_to_rgb("#ff8800")  # → (255, 136, 0)
